# Code of conduct

Keel is built in the open and we want working on it to be straightforward and respectful.

- Be considerate and assume good faith. Critique ideas, data and code, never people.
- Back claims with evidence, and say what you don't know. Disagreement about results is welcome; dismissiveness is not.
- No harassment, personal attacks, discriminatory language or publishing others' private information.
- Don't use the project's spaces to promote tokens, trading signals or paid services.

Maintainers may edit or remove contributions that break these rules and may block repeat offenders. Report concerns privately to the maintainer through GitHub (@gsoffmarket).
